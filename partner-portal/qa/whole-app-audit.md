The normal My Shift browser CI uses the compiled member services and has 40 checks in each engine. The wider `whole-app-browser.mjs` is a discovery and action runner, not a claim of complete acceptance. It uses the compiled existing programme and the exact existing SQLite schema, with fictional protocol-session fixtures and no live network or transport.

Run through the existing Mac workspace check manager. Set `WHOLE_APP_EVIDENCE_DIRECTORY` to an absolute temporary evidence directory. `WHOLE_APP_ACTIONS=true` enables real loaded-UI action checks. `WHOLE_APP_ACTION_FILTER` selects checks requiring follow-up without rerunning passed checks. Supply `WHOLE_APP_LEGACY_MODULE` only for the test bundle built from the read-only, hash-verified serving `shift-programme-v7-retained-live` snapshot. Its original module manifest and deployment/version identity are retained with audit evidence. The snapshot is not a new backend and is never deployed.

The public API adapter is retained at the exact recorded hash; all other absent Core bindings, public images, checkout services and external origins remain explicit unverified 503s. No synthetic success response substitutes for those services. HTTP browser traffic and Node fetch are intercepted. Local, same-origin Blob image previews stay local.

The reusable whole-app fixture is never a production migration.
